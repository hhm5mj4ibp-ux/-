# バックログ（優先度の正）

**運用:** ここが空や古いままだと、複数 AI が別々の「次やること」を推測する。**小さくてよいので常に 1 件以上**「いま着手禁止の最優先」を置く。

## 凡例

| 記号 | 意味 |
|------|------|
| P0 | 今すぐ（本番・全プレイヤー） |
| P1 | 次サイクル |
| P2 | 余裕があれば |
