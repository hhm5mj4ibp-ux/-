# 対局卓 UI 再設計 — 他 AI への指示

親エージェント（このリポジトリの対局ロジック担当）が **対局画面を実卓から作り直す**。ルールと牌スプライトは触らない。画像が必要な作業だけ、画像生成／テクスチャ担当がやる。

## 絶対にやるな

- `TILE_*_POS` / `TILE_HAND_POS`、`7198.png`、`hand-tiles.png` の中身を変えない。
- 和了・配牌・先出後引き・扣聴・宝牌のロジックを変えない。
- Unity / Three.js に書き換えない（2D CSS 卓のまま）。
- `#human-hand`、`#left-area .side-col`、`#top-area .north-hand-row` のセレクタを消さない。

## 牌の置き方（実卓・変更しない）

四方卓。自分は常に手前。

| 席 | 手牌 | 河（捨て） | 鳴き |
|----|------|------------|------|
| 手前 | 卓縁に横一列、立牌 | 手牌の**奥（卓心側）**、6枚で改行 | 手牌の横（向かって左が鳴き） |
| 対面 | 奥の卓縁、裏向き | 手牌の**手前（卓心側）** | 手牌の横 |
| 左 | 左縁、席から見て手前に並ぶ | 卓心側 | 手牌の横 |
| 右 | 右縁、同上 | 卓心側 | 手牌の横 |

中国麻雀の牌河は **左から右へ6枚で次行**。中央はデジタルHUDではなく、風位の木円盤＋伏せ宝牌の木皿。

## 作ってほしい素材（任意・あると実卓に寄る）

ルートに置き、`harbin-mahjong.html` の `.mj-table` CSS が参照する。

| ファイル | 内容 | サイズ目安 |
|----------|------|------------|
| `felt-cloth.jpg` | 真上からの緑フェルト。継ぎ目なし。照明は中央やや明るく周辺暗い | 2048×2048 |
| `table-wood.jpg` | 東北の榆／柞の木目。卓枠用シームレス | 2048×512 |
| `wind-disc.png` | 木の円盤。東南北西。透明背景 | 512×512 |

**禁止:** 牌の絵柄、キャラ、ロゴ、金縁タイトル用の飾り。

## 親が CSS で仮置きしているもの

`.mj-table` の木枠・フェルト・席札・宝皿は CSS グラデで仮実装済み。写真を足したら `background-image` を差し替えるだけでよい。
