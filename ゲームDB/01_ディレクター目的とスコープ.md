# ディレクター目的とスコープ

## 一言で

ブラウザで遊べる **「ハルビン麻雀（カタン／嵌張限定）」** を、2D プレミアム品質の対局体験と **ワンタイム課金（プレミアム）** で売れる製品として維持・改善する。オンラインは部屋コード型（Node サーバ）。ストア公開は Capacitor シェルで後続。

## プレイヤー価値（優先順の目安）

1. **対局が最後まで途切れない**（オフライン・再接続・サーバスリープを含む）  
2. **ルールが説明なくても誤解されにくい**（UI 文言・待ちの見え方）  
3. **オンラインで 2〜4 人が同じ体験**（同期・表示の一貫性）  
4. **商用2Dの見た目・操作感**（タイトル、卓、日常の牌モーション、音）  
5. **プレミアム課金が誤解なく買える**（むずかしい AI・卓テーマ。強さガチャはしない）  

## スコープ内（やる）

- `harbin-mahjong.html` 上のゲームロジック・UI・多言語表示（JA 等）・2D プレミアム演出  
- `server/online-server.mjs` のルーム・同期・簡易 AI 挙動  
- Web 課金（Stripe Checkout / webhook / entitlement）と `legal/` 法務ページ  
- PWA（manifest・アイコン）と `native/` の Capacitor シェル  
- 静的配信・ビルド（`public/`）と `DEPLOY_FREE.md` に沿ったデプロイ  

## スコープ外（原則やらない／別プロダクト）

- 一般麻雀の全ルール対応（本プロダクトは **嵌張のみ和了可能** など強い制約あり → [[04_ルール仕様_コード対応]]）  
- Unity / Three.js への卓の書き換え、牌スプライト内容の変更  
- 実マネーの点数・ギャンブル、強さに効くガチャ  
- ランキングサーバ（未実装のまま仕様に書かない）  

## ディレクター判断がぶれたとき

- **プレイヤーが実際に触ったときに困るか** で決める。  
- 技術的にきれいかより、**本番 URL で再現できるバグ**を優先する。
