# 製品アーキテクチャ

## 構成図（概念）

```text
[ブラウザ / PWA]  index.html → harbin-mahjong.html（ゲーム一式・2DプレミアムUI）
                ↓ HTTP / SSE（ゲーム内「サーバー URL 設定」）
[Node]     server/online-server.mjs（部屋・配牌・同期）
           server/shop.mjs（Stripe Checkout / webhook / entitlement）
[後続]     native/ Capacitor シェル → App Store / Google Play（IAPは別実装）
```

## 主要パス（実装の地図）

| 領域 | パス | メモ |
|------|------|------|
| エントリ | `index.html` | `harbin-mahjong.html` へ誘導 |
| クライアント本体 | `harbin-mahjong.html` | UI・和了判定・オンライン UI 文字列など単一ファイルに集約 |
| オンラインサーバ | `server/online-server.mjs` | `PORT` 環境変数。ルーム TTL・最大人数など |
| ビルド | `scripts/vercel-static-build.mjs` | ルート資産を `public/` に複製（Vercel の出力先） |
| 牌画像等 | `tiles/`、`7198.png`、`hand-tiles.png`（自家手牌、元 `名称未設定のデザイン (2).png` と同一） | ビルドで `public/` へ（必須） |
| 音 | `audio/`（SE・BGM の ogg） | ビルドで `public/audio/` へ |
| 法務 | `legal/` | 特定商取引・プライバシー・利用規約 |
| PWA | `manifest.webmanifest`、`sw.js`、`icons/` | ホーム画面追加 |
| ストアシェル | `native/` | Capacitor。IAP は未接続 |
| 課金 | `server/shop.mjs` | `STRIPE_*` 環境変数。未設定時は全機能アンロック |
| デプロイ文書 | `DEPLOY_FREE.md`、`render.yaml`、`vercel.json` | 無料枠手順 |

## 技術スタック

- フロント: 静的 HTML / CSS / ブラウザ上の JS（ビルドステップは主にファイルコピー）  
- サーバ: Node.js（標準 `http`）。Stripe REST は `fetch`（追加 npm 依存なし）  
- ホスティング: 文書どおり Vercel（静的）+ Render 等（サーバ）を想定  
- 課金環境変数: `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` / `STRIPE_PRICE_PREMIUM` / `SHOP_SUCCESS_URL` / `SHOP_SIGNING_SECRET`
