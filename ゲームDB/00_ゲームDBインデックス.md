**ディレクター（人間）の最低限ルール**

- 仕様変更や優先度変更は **先に `05_バックログ` か `90_決定ログ` を更新**してから実装依頼する。  
- 本番 URL・接続先は **`02` に「現在」欄**を置き、変えたら日付と一緒に更新する。  
- ユーザーが触るための **お試し URL は毎回**出す（`npm run preview`。Vercel preview は SSO で入れない）。  
- AI に渡すときは **「上記の読む順で 01→05 を読んでから着手」** と一文添える。
