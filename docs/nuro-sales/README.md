## 印刷手順（HTMLから再出力する場合）

1. HTML を Chrome / Edge で開く
2. 印刷 → 用紙 **A4**、向き **横**
3. 余白 **なし**（または最小）、背景グラフィック **オン**
4. PDF に保存
