# ソース・オブ・トゥルース（複数 AI 同期）

## 原則

**GitHub 上のこのリポジトリが唯一の同期点です。**  
Obsidian Sync・Google Drive などは「自分用の快適さ」用であって、**AI や他メンバーと状態を揃える正**ではありません。

1. **決まったこと** → Markdown で書く（`ゲームDB/` または `メモ/`）  
2. **`git commit` → `git push`**  
3. 別の AI／別端末では **`git pull`** してから会話を始める  

これで「各 AI 間」は **同じファイルツリー**で同期されます。

## AI に依頼するときの定型文（コピペ用）

```text
リポジトリルートを前提にする。まず次をこの順で読んでから着手:
- AGENTS.md
- ゲームDB/00_ゲームDBインデックス.md（記載の読む順に従う）
変更したら、ゲームDB/90_決定ログ.md に一行追記し、理由を書く。
```

## Obsidian 専用の同期（任意）

- **Obsidian Sync**: 同一 Vault を端末間で同期（Git と二重管理になるので、**コード変更は Git を正**にする）。  
- **Git LFS**: 大画像を増やす場合のみ検討。現状は通常 Git で十分なサイズ感。
